# Surveillance cuisinière

Documentation complète : https://github.com/Joseph7457/ha-surveillance-cuisiniere

## En bref

1. Installez et démarrez **Mosquitto broker**.
2. Renseignez l'adresse IP de la caméra et le **compte caméra** (pas votre compte cloud) dans l'onglet *Configuration*.
3. Démarrez l'add-on et vérifiez dans le *Journal* : `Flux vidéo connecté`.
4. Ouvrez **Cuisinière** dans la barre latérale → *Dessiner les zones*, tous les feux sur OFF.

⚠️ Aide et système d'alerte uniquement : ne remplace ni un détecteur de fumée ni une sécurité de cuisinière certifiée.

⚠️ Pour mettre à jour, n'utilisez jamais « Désinstaller » : la configuration et les zones seraient effacées.
